# Daftar (دفتر)

**Installers and updates for Daftar**, a desktop bookkeeping program for Windows, in Arabic and
English: payment and journal vouchers, cash book, American journal, account statements, VAT
summary, year balance, month-end exports, printing, backups and online updates.

**Download:** the latest setup file is under [Releases](../../releases/latest). Double-click it to
install; no administrator rights are needed. Installed copies update themselves from here
(Settings → Updates), and every update is signed.
